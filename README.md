One line: the text a smart fridge sends its owner at 3am.

> You keep opening me like the answer will change. It's still just condiments and regret.

Built for the [make.fun](https://make.fun/bounty/u-deysumbrella-the-3am-fridge-text-4c3e721d) bounty "The 3AM Fridge Text".

## How it works

`main.py` writes the line to `/output/entry.txt` and checks it against the bounty gate (1–140 characters, UTF-8, one line, not whitespace-only) before writing.

```sh
python3 main.py
cat /output/entry.txt
```
